# fastapi-demo

Small task-management API showing how a project generated by the **AI Software Engineering
Kit** looks and is developed. Demo only: no authentication, in-memory storage.

| | |
|---|---|
| Type | Backend API |
| Technology | Python + FastAPI |
| Database | None (in-memory adapter) |
| Deployment | Docker + Kubernetes (RKE Staging and Prod) |

## How this project was created

```bash
ai-project init examples/fastapi-demo -y --name fastapi-demo --profile backend-api \
  --technology python-fastapi --database none --assistants claude-code,copilot,codex
```

The kit generated `AGENTS.md`, `CLAUDE.md`, `.github/copilot-instructions.md`, `.ai/`
(agents, rules, workflows, stack guides, context), the docs skeleton and the folder layout.
Then the application was built by following `.ai/workflows/new-project.md` and
`.ai/workflows/new-feature.md`: context completed, ADR 0002 written, code + tests + docs.

## Getting started

```bash
python -m venv .venv
.venv/Scripts/activate            # Windows  (Linux/macOS: source .venv/bin/activate)
pip install -e ".[dev]"
uvicorn fastapi_demo.main:app --reload --app-dir src
# open http://127.0.0.1:8000/docs
```

## Configuration

| Variable | Default | Description |
|---|---|---|
| `LOG_LEVEL` | `INFO` | Python logging level |

No secrets are needed. Real secrets, if any were added, would be injected through Kubernetes
Secrets, never stored in `.env` files.

## Tests and quality

```bash
pytest            # unit + integration tests, with coverage
ruff check . && ruff format --check .
mypy              # strict mode
ai-project doctor # kit conformity
```

## API

| Method | Path | Description |
|---|---|---|
| POST | `/api/v1/tasks` | Create a task `{"title": "..."}` |
| GET | `/api/v1/tasks?limit=20&offset=0` | List tasks |
| GET | `/api/v1/tasks/{id}` | Get a task |
| POST | `/api/v1/tasks/{id}/complete` | Complete a task (409 if already done) |
| GET | `/health/live`, `/health/ready` | Kubernetes probes |

Errors use RFC 9457 problem details (`application/problem+json`).
