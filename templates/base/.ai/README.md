# .ai/ — AI engineering configuration

Generated by the AI Software Engineering Kit v{{ kit_version }} (profile: {{ profile }}).
The entry point for AI assistants is `AGENTS.md` at the project root.

| Path | Owner | Purpose |
|---|---|---|
| `agents/` | kit (CORE) | Specialised agent roles; `00-master.md` orchestrates |
| `rules/` | kit (CORE) | Technology-agnostic engineering rules with citable IDs |
| `workflows/` | kit (CORE) | Step-by-step processes (feature, bug fix, release...) |
| `stacks/` | kit (CORE) | Technology-specific guidance |
| `context/project.md` | **project** | What this project is: requirements, constraints, risks |
| `custom/` | **project** | Your overrides and extra rules; they win over kit files |
| `kit.lock.json` | kit | Kit version, selection and hashes of CORE files (commit it) |

## Customising

Do not edit CORE files: `ai-project update` refreshes them, and local edits become conflicts
(`*.kit-new` files) to merge by hand. Write project-specific instructions in `custom/` instead.

## Commands

```bash
ai-project doctor          # check the setup (use in CI)
ai-project update --dry-run
ai-project update          # refresh CORE files, keep your customisations
```
